Contracts come live from HighLevel via /.netlify/functions/esign?action=documents (HL GET /proposals/document) and templates via action=templates (HL GET /proposals/templates) — the same lists the e-sign sheet reads. No rows are ever invented: if a call fails, this page says so instead of showing old or made-up contracts. Click any row to open it. Nothing sends on its own: a contract goes out only when Troy taps Send on that one contract's detail view and confirms — never automatically, never in a batch.

What this list shows now (enriched Nov 27, 2026): the documents feed returns links[] + createdAt per document, and the server joins the seller contact's phone + address + contract price — so the Property column shows the seller's address, Sent shows the created date, Price shows the seller contact's contract_price field (the same price the e-sign sheet validates; a document grandTotal above $0 is the fallback — drafts read $0.00, which means "no price on the document", not $0), the Signing link column shows the seller's own signing link — HighLevel's API returns no URL on a link record, only a referenceId, so the server builds the link as https://sendlink.co/documents/v1/<referenceId>?locale=en-US (proven from HighLevel's own signing email, Nov 27, 2026); drafts carry no links at all, links are minted at send), and the Contact / Thread column links straight into the Conversations thread (?thread=<phoneKey>) when the seller has a phone. Viewed shows the viewed date when the document is viewed and no recipient has signed — that date is the document's last update, which is the view event in that case; once a signer has signed, the last update is the signature, not the view, so Viewed shows “—” with the reason. What it still cannot show: signed date shows only when a recipient record carries signedDate / signedAt; the document record itself carries no APN or legal description — the Property column is the seller contact's mailing address, not the legal description. Any field the feed does not carry shows an honest “—” — nothing is invented. The seller is the first signer recipient who is not the buyer signer (Paula Thomas) or Troy — co-sellers after the first are listed under the seller name.
